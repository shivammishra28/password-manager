# 🔐 Password Manager

A simple and secure Password Manager built with **Vite + React**, styled using **Tailwind CSS**. Store, manage, and copy your passwords and usernames easily — all in one place.

---

## 🚀 Features

- 📋 Add, Edit, and Delete Password Entries
- 👀 Show and Hide Passwords
- 🔗 Open and Copy Website URLs
- 📎 Copy Username and Password to Clipboard
- ⚡ Superfast Performance with Vite
- 🎨 Styled with Tailwind CSS
- 🧱 Font Awesome Icons Integration

## 📦 Installation

```bash
# Clone the repository
git clone https://github.com/shivammishra28/password-manager.git

# Navigate into the folder
cd password-manager

# Install dependencies
npm install

# Start the development server
npm run dev

🧪 Usage

1)Open your browser and go to http://localhost:5173

2)Start adding your password entries.

3) Click copy/edit/delete icons to manage entries.
